# QA Orbit in Action

## Evidências utilizadas

A seção pública foi escrita a partir de fontes verificadas no repositório privado `leoschmitt98/QAorbit`:

- README operacional do projeto;
- `package.json` da branch principal;
- histórico recente de commits;
- documentação declarada dos módulos e suas limitações.

## Alegações publicadas

### Estado

- Aplicação privada e local-first.
- Frontend React/Vite, backend Express e persistência SQL Server.
- Desenvolvimento ativo.
- Foco recente comprovado pelo commit `Add QA Orbit automation foundations`, de 8 de julho de 2026.

### Módulos

- Smart Recorder.
- Automation Builder.
- QA Runner.
- Database Explorer.
- SQL Quality Analyzer.
- QA Orbit Labs.

### Princípios

- Execução local e controlada.
- Arquitetura modular.
- Blueprints neutros em relação ao framework.
- Comandos com allowlist e bloqueio de padrões perigosos.
- Sanitização de stdout, stderr e informações sensíveis.
- SQL gerado para revisão, sem execução automática no banco do cliente.
- Contexto assistido por IA preparado localmente, sem chamada automática a APIs externas.

- Disponibilidade pública.
